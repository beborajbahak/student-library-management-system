# Stakeholder Identification

| Stakeholder | Role | Needs and Interests |
|---|---|---|
| Students | End users | Search, borrow, and return books and view borrowing information |
| Librarian | System operator | Add books, update records, manage borrowing, and prepare reports |
| Administrator | System owner | Manage user accounts and control access |

Students are the main users of the system. Librarians manage the books and borrowing activities, while administrators manage user accounts and access.
