# Student Library Management System

A React + Vite Student Library Management System made for the CSE 220 course project.

## Main features
- Admin, Librarian, and 10 Student accounts
- Student names: Bebo, Aasha, Prashna, Reshma, Shakti, Prabesh, Abib, Anurat, Puzan, Sabin
- Dashboard
- Manage Books
- Manage Users
- Issue and Return Books
- Requested Books
- Status
- Student Information
- Profile
- Notifications/account controls
- LocalStorage data for demo use
- React Router pages, so menu buttons open inside the app without manually typing localhost URLs

## Run
```bash
npm install
npm run dev
```
